



| ID   | Flik          | User story                                                                                                                                                                 |
|------|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| US01 | Katalog       | Som en användare vill jag <br> se en katalog med en lista över böcker<br>så att jag vet vilka böcker jag kan välja från.                                                   |  
| US02 | Katalog       | Som en användare vill jag <br>kunna favoritmarkera en enskild bok i katalogen<br>så att jag enkelt ser vilka böcker som intresserar mig.                                   |
| US03 | Katalog       | Som en användare vill jag <br>kunna avmarkera en bok som favorit i katalogen<br>så att jag kan ta bort böcker när mitt intresse förändras.                                 |
| US04 | Lägg till bok | Som en användare vill jag <br>kunna lägga till en bok i katalogen <br>så att katalogen över böcker kan kompletteras med fler böcker.                                       |
| US05 | Mina böcker   | Som en användare vill jag <br>se en lista över enbart mina favoritmarkerade böcker<br>så att jag ser de böcker som intresserar mig.                                        |
| US06 | Statistik     | Som en användare vill jag <br>se statistik över antal böcker och samtliga användares favoritmarkeringar<br>så att jag får en överblick över antal böcker och favoriter.    |
| US06 | Alla          | Som en användare vill jag <br>kunna klicka på knappar för funktionerna Katalog, Lägg till bok, Mina böcker och Statistik<br>så att jag kan nå den den funktion jag behöver |
